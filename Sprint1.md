## Work Summary (Developer Facing) 

We implemented many different functionalities during sprint 1. First couple things included were some camera controls which included a camera where you can move around the map with WASD. This also includes a zoom functionality where you can zoom with your scroll wheel. Other UI implementations include a simple main menu and settings with a pause menu. A map generation was included with an animation that can control the speed and size of the generation. A simple creature was created where you can control how fast the program moves. The last thing included was a creature statistic placeholder where we can store and get information all about the creature.
